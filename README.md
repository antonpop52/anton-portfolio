# Антон Попов — портфолио

Сайты, Telegram-боты и автоматизации.

## Сайт

https://antonpop52.github.io/anton-portfolio/

## Запуск

Статический проект на HTML, CSS и JavaScript. Для локального просмотра выполните `python3 -m http.server 8768`.

Основные файлы: `index.html`, `style.css`, `process-build.css`, `app.js`. Ресурсы находятся в `assets`, демонстрационный проект — в `demos`.

Форма проверяет поля и готовит письмо через `mailto`; серверной отправки сообщений нет.

## Оформление

Композиция адаптирована по предоставленному референсу Wix Design Wrap. Русские SVG-заголовки и волна реализованы в коде. Пользовательская модель MacBook экспортирована из Blender. Шрифт Coders Crux использован из исходного референса.
